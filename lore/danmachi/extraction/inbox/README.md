# Entrada de materiales para extracción

Registrar aquí un manifiesto por cada material que vaya a analizarse. No es necesario duplicar archivos binarios ni almacenar texto protegido completo.

Cada manifiesto debe indicar:

- Identificador de fuente ya asignado o estado `ID_PENDING`.
- Título, autor/editorial cuando se conozcan, edición, idioma y formato.
- Continuidad objetivo y justificación.
- URL/ruta de origen y fecha de acceso.
- Qué contenido fue realmente accesible (texto, imágenes, índice, metadatos o solo ficha comercial).
- Restricciones, errores de acceso y límites de extracción.
- Hash/versión del archivo cuando sea posible.
- Tarea de extracción asociada y ubicación del checkpoint.

No reutilizar un ID de fuente ni registrar metadatos de producto como si fueran lectura narrativa.
