# Trabajo de extracción en curso

Guardar aquí notas de trabajo por volumen, capítulo o rango de páginas. Cada archivo debe enlazar el manifiesto de `../inbox/` y el checkpoint correspondiente.

Formato recomendado de nombre: `<continuidad>-<obra>-vol<NN>-<bloque>-<tarea>.md`.

Mantener separados:
- observación directa de la fuente;
- paráfrasis de la escena;
- interpretación o hipótesis;
- discrepancias de traducción;
- candidatos a entidades/eventos;
- decisiones de promoción o descarte.

El material de esta carpeta es provisional hasta que se contraste y se incorpore al registro canónico correspondiente.
