# Checkpoints de extracción

Un checkpoint debe permitir reanudar el trabajo sin repetir bloques ya terminados. Registrar siempre:

- tarea, continuidad, obra/volumen y fuente;
- rango/unidad completada y siguiente unidad exacta;
- pasadas realizadas y resultado de cada una;
- entidades/eventos/relaciones revisados y si se reutilizaron IDs;
- dudas, contradicciones y tareas pendientes;
- archivos modificados y estado de integración;
- pruebas ejecutadas y evidencia verificable (o indicar expresamente que no se ejecutaron).

No cerrar una tarea mientras queden pendientes declarados por su criterio de cierre.
