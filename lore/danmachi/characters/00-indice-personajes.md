# Índice maestro de personajes

## Convenciones

Las entradas se consideran candidatos para fichas, no datos cronológicos ya verificados. El mismo personaje tendrá un único ID estable, más alias y estados por época. No crear una segunda ficha solo porque cambie de afiliación, edad, nombre conocido o condición.

## Regla de identidad y duplicación

Antes de crear una ficha nueva, buscar nombre, romanización, traducción, alias y relaciones en este índice y en \`catalog.json\`. Si es la misma persona, añadir el alias al ID existente. Si existe duda de identidad, conservar dos candidatos enlazados con estado IDENTITY_UNRESOLVED hasta contar con evidencia.
