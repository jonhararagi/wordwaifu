# Catálogo de poderes, costes y evolución

El sistema de poderes se diseña como una regla narrativa persistente, no como una cifra aislada. Cada poder debe poder registrarse con estas dimensiones:

- **Familia o categoría:** físico, mental, sensorial, elemental, espacial, temporal, transformación, soporte, información, estrategia/técnica, pacto, contrato, artefacto o híbrido.
- **Potencia y alcance:** escala inicial y máxima, número de objetivos, distancia, duración y precisión.
- **Perfil:** fuerte, débil pero versátil, técnico, estratégico/de inteligencia, de alto coste, de pacto, de contrato, heredado, prestado, compartido o parasitario.
- **Activación:** mirada directa, voz, contacto, gesto, preparación, objeto, condición emocional, nombre verdadero, consentimiento, señal o requisito contextual.
- **Coste y pago:** energía, tiempo, memoria, salud, años de vida, autonomía, vínculos, reputación, deuda o riesgo para terceros. Aclarar cuándo se cobra y si puede evitarse.
- **Límites y contramedidas:** condiciones de fallo, inmunidades, interrupciones, resistencias, usos prohibidos y qué no puede resolver.
- **Vínculo contractual:** partes, términos, consentimiento o coerción, obligaciones, sanciones, incumplimiento, renegociación y forma de terminarlo.
- **Evolución por etapas:** requisito de desbloqueo, nueva capacidad, aumento de alcance, coste nuevo, pérdida de control, cambio de activación y consecuencias sociales/psicológicas.
- **Irreversibilidad:** marcar qué cambios pueden deshacerse, cuáles exigen un precio excepcional y cuáles son permanentes.

## Etapas recomendadas

1. **Latente:** señales involuntarias, efectos pequeños o activación incierta.
2. **Despertar:** aparece una capacidad controlable, con condición y coste explícitos.
3. **Dominio:** mejora precisión, eficiencia o variedad, sin borrar las debilidades centrales.
4. **Sobrecarga o corrupción:** se amplía el poder a cambio de una deuda, pérdida, daño o peligro verificable.
5. **Umbral irreversible:** cambia de forma permanente la capacidad, el vínculo o el usuario; puede dejar de poder apagarse, alterar la identidad o hacer permanente una orden.
6. **Integración o resolución:** el personaje aprende a convivir con el poder, rompe el vínculo pagando el precio establecido o acepta una consecuencia definitiva. No todos los poderes necesitan alcanzar esta etapa.

Son etapas sugeridas, no una escala obligatoria. Un poder puede tener dos, tres o más fases y puede degradarse, fragmentarse, sellarse o evolucionar de forma lateral.

## Ejemplo de diseño: mandato por contacto visual

Ejemplo original inspirado en el patrón de poderes con condiciones estrictas, no una ficha de canon:

- **Tipo:** mental / mandato / contrato.
- **Activación:** el usuario debe ver directamente los ojos del objetivo y formular una orden audible.
- **Potencia:** puede imponer una orden breve; no controla automáticamente todos los pensamientos.
- **Límites:** no funciona a través de grabaciones; una orden por objetivo; la interpretación literal puede producir resultados inesperados.
- **Coste inicial:** agotamiento y pérdida temporal de recuerdos recientes.
- **Etapa intermedia:** órdenes más duraderas; el coste afecta recuerdos personales y vínculos.
- **Umbral irreversible:** la facultad queda permanentemente activa o ya no puede desactivarse a voluntad; el usuario puede activar el poder sin querer y pierde una parte de su autonomía.
- **Contrajuego:** evitar la mirada, interrumpir la orden, usar protección específica o explotar una ambigüedad conocida.
- **Consecuencia dramática:** los aliados modifican cómo hablan y miran al usuario; el poder más fuerte puede volver más difícil la intimidad y la confianza.

El autor debe decidir qué condiciones son verdaderas en su universo. El sistema no debe copiar automáticamente reglas exactas de una franquicia.

## Reglas de continuidad para las evoluciones

- Cada etapa tiene que indicar **qué cambió, por qué, cuándo y con qué evidencia**.
- Un nuevo nivel no elimina silenciosamente los costes anteriores; debe declarar si los reduce, transforma o aumenta.
- Si una condición se vuelve permanente, las escenas futuras deben tratarla como tal.
- Las reglas no se alteran retroactivamente para salvar al protagonista. Si se descubre una regla nueva, debe existir una razón diegética para que antes se desconociera.
- Registrar qué personajes conocen cada condición, coste, punto débil y evolución.
- Los poderes deben afectar tácticas, relaciones y conflictos cotidianos, no solo las escenas de combate.
- Para balancear una capacidad dominante, incluir límites, precio, tiempo de preparación, contramedidas o consecuencias que no se solucionen con fuerza bruta.

## Formato rápido del catálogo

Una ficha de poder puede usar esta plantilla en el editor:

`Nombre / categoría / perfil / potencia y alcance / activación / coste / límites / contramedidas / etapas / requisito de evolución / cambios irreversibles / quién conoce la regla`

El catálogo del editor se conserva como texto estructurado por bloques y puede exportarse/importarse junto con el manuscrito Markdown. El registro facilita la continuidad; no significa que la aplicación ya simule o balancee automáticamente cada poder.


## Catálogo estructurado de poderes

El panel «Poderes y habilidades» permite crear, editar, buscar y eliminar fichas independientes. Cada registro separa activación, coste, límites, evolución, consecuencias, contrato, inspiración y fuente; puede vincularse por ID estable a un personaje y a una historia. El generador solo prepara un candidato original y no lo persiste hasta que se confirma el formulario. El esquema valida referencias y preserva powers[] en importación/exportación. No se deben presentar las plantillas del generador como habilidades canónicas.
